# FileProcessing（文件处理工具）

## 项目简介

FileProcessing 是一款基于 Qt 5.6 的 Windows 桌面应用程序，提供**文件拆分**和**图片格式转换**两大核心功能。项目使用 C++ 开发，基于 Visual Studio 2013 (v120 工具集) 构建，支持 Win32 和 x64 双平台。

当前版本：**v3.0.0**

---

## 功能概览

### 一、文件拆分

将大文件按指定大小拆分为多个小文件，支持单线程和多线程并行两种模式。

| 特性 | 说明 |
|------|------|
| 拆分单位 | 支持 KB / MB / GB 三种粒度 |
| 大文件支持 | 64位文件操作，支持 >2GB 文件 |
| 缓冲策略 | 4MB 缓冲区读写，平衡内存占用与 I/O 效率 |
| 并行拆分 | 多线程加速（1-16 线程），适用于大文件和 SSD 存储 |
| 输出命名 | 格式为 `001_原文件名.ext`、`002_原文件名.ext` ... |
| 自定义输出 | 可指定输出目录，默认输出到源文件所在目录 |
| 取消操作 | 支持随时取消正在进行的拆分任务 |
| 实时进度 | 进度条 + 预估分块数 + 彩色日志输出 |

### 二、图片格式转换

支持 BMP、JPEG、PNG、ICO、HEIC 五种格式之间的相互转换。

| 特性 | 说明 |
|------|------|
| 转换模式 | 单文件转换 + 批量转换（双标签页） |
| 格式支持 | BMP ↔ JPEG ↔ PNG ↔ ICO ↔ HEIC |
| 质量控制 | JPEG / HEIC 可调节编码质量（1-100） |
| HEIC 支持 | 基于 libheif 实现 HEIC 解码与编码，支持 Alpha 通道 |
| 批量操作 | 可添加文件/文件夹，支持移除、清空 |
| 覆盖策略 | 可选覆盖已存在文件或跳过 |
| 取消操作 | 支持随时取消正在进行的转换任务 |
| 实时进度 | 进度条 + 状态标签 + 彩色日志输出 |
