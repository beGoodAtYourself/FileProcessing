## Phase 1: 格式与 SVG 保存

- [x] 1.1 在 `ImageFormat` 末尾追加 `FORMAT_SVG = 5`；补全 `getFormatExtension()` 和 `getFormatName()`，保持现有枚举值和默认格式。
- [x] 1.2 在现有引擎文件中新增私有 SVG 保存辅助函数，用 QBuffer 编码 PNG、Base64 内嵌、QXmlStreamWriter 输出尺寸和命名空间，保留解码后的 Alpha。
- [x] 1.3 用 QSaveFile 实现完整写入后提交；检查 PNG 编码、文件打开、XML/设备写入及提交错误，禁止直接覆盖回退，提供包含路径及失败阶段的日志。

- [x] 1.5 增加可重复运行的核心验证入口及使用说明：解析导出的 XML，验证命名空间、尺寸、内嵌 PNG 和 RGBA 一致性；验证不同质量值不改变 SVG 中的图片内容。
